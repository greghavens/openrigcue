Forza Horizon 5 sends telemetry through its built-in Data Out settings, including the Steam version.

  1. In Forza Horizon 5, open Settings > HUD and Gameplay.
  2. Under UDP Telemetry Settings, set Data Out to On.
  3. Set Data Out IP Address to 127.0.0.1 when the game and OpenRigCue run on the same PC.
  4. Set Data Out IP Port to ^port^.
  5. Save the settings and drive a car to start sending telemetry.

Steam on Linux/Proton does not need a Windows loopback utility.

If another telemetry app uses this port, close it or use OpenRigCue's port forwarding to share the data.

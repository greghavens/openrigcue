Forza Motorsport 7

  1. Open the game’s HUD / HUD and Gameplay settings and locate Telemetry or Data Out.
  2. Turn Data Out on.
  3. Set the Data Out destination address to 127.0.0.1 and its UDP port to ^port^.
  4. Set the Data Out packet format to CAR DASH.
  5. Save the settings and drive a car to start telemetry.

Steam on Linux/Proton does not need the Windows loopback utility. If another telemetry application uses this port, configure forwarding or close that application before connecting.

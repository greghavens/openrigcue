F1 2020 console

  1. Open Game Options → Settings and find UDP Telemetry Settings.
  2. Enable UDP Telemetry, disable Broadcast Mode, and select a 60 Hz send rate.
  3. Set the destination address to ^ip^ and the UDP port to ^port^.
  4. Choose 2020 as the UDP Format.

PS4 alternative: select F1 2019 on OpenRigCue’s console page, then use the 2019 UDP format and port 20780 in the game. Keep the destination address set to ^ip^.

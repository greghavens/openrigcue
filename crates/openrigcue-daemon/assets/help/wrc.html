WRC Generations

  1. Close the game and open Documents/My Games/WRCG/UserSettings.cfg.
  2. If the file is missing, start the game, change the master volume, and exit to create it.
  3. Apply the settings below, save the file, and restart the game.
WRC.Telemetry.TelemetryRate = 60
WRC.Telemetry.TelemetryAddress = "127.0.0.1"
WRC.Telemetry.EnableTelemetry = true
WRC.Telemetry.TelemetryPort = ^port^

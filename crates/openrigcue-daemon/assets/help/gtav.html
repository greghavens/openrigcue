Grand Theft Auto V

  1. Install Script Hook V and Community Script Hook V .NET for your installed GTA V version.
  2. Install the GTA5Mod files supplied by GTA5SimFeedback in the GTA V installation directory.
  3. Start the game with its telemetry mod enabled.

Use the GTA5SimFeedback project’s installation guide and downloads for the required components. OpenRigCue receives the game’s telemetry; the separate SimFeedback plugin is not needed for OpenRigCue.

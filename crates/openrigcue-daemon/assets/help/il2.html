IL-2 Sturmovik

  1. Close the simulator and open data/startup.cfg inside its installation directory.
  2. Update both motiondevice and telemetrydevice as shown below, then save the file.
  3. Restart the simulator.
[KEY = motiondevice]
addr = "127.0.0.1"
decimation = 1
enable = true
port = ^port^
[END]

[KEY = telemetrydevice]
addr = "127.0.0.1"
decimation = 1
enable = true
port = ^port^
[END]

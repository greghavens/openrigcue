Richard Burns Rally

  1. Enable the Next Generation Physics (NGP) plugin.
  2. Open Options → Plugins → NGP and press U to enable UDP telemetry.
  3. If needed, close the game and set the following entries in RichardBurnsRally.ini, then restart.
udpTelemetry = 1
udpTelemetryAddress = 127.0.0.1
udpTelemetryPort = ^port^

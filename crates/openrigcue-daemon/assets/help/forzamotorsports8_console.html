Forza Motorsport console

  1. Open the game’s HUD / HUD and Gameplay settings and locate Telemetry or Data Out.
  2. Turn Data Out on.
  3. Set the Data Out destination address to ^ip^ and its UDP port to ^port^.
  4. Set the Data Out packet format to CAR DASH.
  5. Save the settings and drive a car to start telemetry.
